# Multi-Agent Prompt — Planning Modules MVP Implementation

## Objective

A file named **PLANNING** exists in the working directory. Analyze it completely. It contains three modules that need to be developed for our Manufacturing ERP.

Do not modify the original file.

## Tasks

1. Analyze every section of the PLANNING file.
2. Conduct independent research on how leading ERP/MES platforms implement similar modules.
3. Recommend the best technology stack for each module.
4. Create **three separate `plan.md` files**, one for each module.

## Each plan.md must include

- Module Overview
- Objectives
- User Personas
- Functional Requirements
- Non-functional Requirements
- UI/UX Flow
- Screen-by-Screen Design
- Navigation
- Database Schema
- API Design
- Backend Logic
- Frontend Components
- AI Features
- Security
- Validation
- Testing
- MVP Scope
- Future Roadmap

## Technology Research

Compare approaches used by ERPNext, Odoo, SAP, Oracle NetSuite, Microsoft Dynamics 365, Siemens Opcenter, Epicor, Plex and Infor.

Recommend:

- Frontend
- Backend
- Database
- Authentication
- APIs
- Real-time architecture
- Charts
- AI integration
- Deployment

Explain why each choice is appropriate.

## MVP Requirements

There is no real backend data.

Create realistic demo data including:

- 5–10 pilot customers
- Factories
- Products
- Machines
- Employees
- Production orders
- Inventory
- Reports
- Alerts
- AI summaries

Use believable sample names and manufacturing data suitable for investor demonstrations.

## Deliverable

Produce three independent `.md` implementation plans that act as engineering blueprints and are detailed enough for frontend, backend, AI and product teams to begin development immediately.
